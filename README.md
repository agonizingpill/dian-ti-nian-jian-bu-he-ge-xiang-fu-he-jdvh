# lift-inspection-review

电梯年检不合格项复核工作台，服务南京景诚特种设备检测团队。应用把电梯档案、逐项检验、整改通知、复检证据和合格证签发串成一条可审计流程。

## 业务范围

- 操作员录入设备与检验项，失败项生成整改通知并预约复检。
- 主管审核复检结果并签发合格证，安全回路与制动器关键项一票否决。
- 复检证据必须使用原检验项编码，照片错配会被后端拒绝。
- worker 使用 `DecisionTreeClassifier(random_state=1066, max_depth=3)` 计算分流结果并导出规则路径。

## 业务核验模块

登录后打开页面右下角的「业务核验」。可从实时业务台账筛选记录、导出所选结果，主管可对当前证据签认并填写说明。

- **年检到期排程** 按年检到期日排序并标出近 30 天到期与逾期资产，供检验员安排路线。
- **关键项整改督办** 聚合关键不合格项及整改资料，未开单、过期或缺复检记录可分别交接。
- **证书有效性对照** 对照证书有效期与资产仍未验证的关键缺陷，保留主管判断依据。

### 二次扩展核验

- **复检影像归属核验** 把复检照片与原不合格项编号逐一对照，识别缺影像和串项证据。
- **复检员同档排班冲突** 按复检员与相同预约时点核对尚未完成的排班，重约或关闭后自动释放冲突。

## 业务处置与验收

登录后打开「复检补证与改约」。操作员提交结果、凭证号和说明，主管可复核关闭或退回补证，观察员可查看记录。关闭时复查源业务状态，处置历史保留每次操作。

- 同档复检改约验收

## 分流树版本切换（主管）

登录后打开页面右下角的「分流树版本」。版本注册表与生效指针持久化在数据库中，能力边界如下：

- **两版并存、可回退**：`tree-v1-1066` 为基线版，`tree-v2-2026-trial` 为主管试用版；两版在多组检验项上给出不同建议（脚本 `scripts/verify_triage_versions.py` 可离线验证），关键安全项失败在两版中都保持 `hold`。主管填写原因即可切换，不合适再切回，每次切换写入审计轨迹。
- **加载失败保留旧版、照常接单**：启用前会先构建并冒烟校验模型，失败则拒绝切换，生效指针不变；接单时若固化版本无法构建，自动回退基线版并留痕，不阻断接单。
- **按接单时版本固化**：复核单在接单的同一条 `INSERT ... SELECT` 中读取生效指针并写入 `analysis_jobs.model_version`，切换与并发接单交叉时，每张单都按接单瞬间生效的版本计算，事后切换不会改写历史单。
- **中断恢复不换模型、不重复出结论**：worker 启动与后端启动时会把遗留的 `running` 任务重新入队，版本不变；worker 用 `queued → running` 的 compare-and-set 抢占，队列重复投递不会产生第二份结论；失败重试仅针对 `failed` 单，沿用原版本。
- **可查询**：版本面板展示当前生效版本、每个版本的加载状态与两版差异预览，并列出每张复核单实际使用的版本；检验复核页的复核结果上也有版本标记与失败重试入口。
